# 🎮 Python Mini Games

A beginner-friendly Python project that combines two simple and fun games in one application.

## 🎯 Games Included

### ✊ Rock Paper Scissors
Play Rock Paper Scissors against the computer. The computer randomly selects rock, paper, or scissors, and the program determines the winner.

### 🔢 Number Guessing Game
Try to guess a randomly generated number between 1 and 100. The game provides hints such as "Too high" or "Too low" until you find the correct number.

## ✨ Features

- 🎮 Simple game menu
- ✊ Rock Paper Scissors
- 🔢 Number Guessing
- 🤖 Computer-generated choices
